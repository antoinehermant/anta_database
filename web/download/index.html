Download the data

The AntADatabase gathers published radar isochrones (internal reflecting horizons, IRHs) of Antarctica, with their ages, in one format. Each radar line is an HDF5 (netCDF) file, with the depth of each IRH along the line. It is free to download. Please cite the datasets you use.

Recommended With the Python package

The anta_database package downloads the whole database for you (about 630 MB) and checks every file. Later updates only download what changed, and the package tells you when a new version is published. 

pip install anta_database
from anta_database import Database

db = Database()
db.sync()   # downloads the database, or updates it

Or from the command line: anta-sync. Then query, plot and load the data in Python: see the Quick Start guide.

Or choose datasets in the catalogue

Choose datasets below and download them in one zip file. With Select all, the zip holds the whole database (an AntADatabase directory, with its index AntADatabase.db), which also works with the Python package: Database("path/to/AntADatabase"). With some datasets only, the zip holds the directories of the chosen datasets.
