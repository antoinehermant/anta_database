Download the data

The AntADatabase gathers published radar isochrones (internal reflecting horizons, IRHs) of Antarctica, with their ages, in one format. Each flight line is an HDF5 (netCDF) file, with the depth of each IRH along the line.

We recommend downloading the whole database (Select all): the zip then holds an AntADatabase directory, with the index of the database (AntADatabase.db), ready to use with the anta_database Python package (pip install anta_database), which can also update it later.

If you only need some datasets and will not use the Python package, you can also download just these: the zip then holds the directories of the chosen datasets.

Please cite the datasets you use.
